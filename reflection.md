During this project, with the assistance of Copilot, it was more convenient to write the code. However, the AI sometimes used the wrong column names and ignored empty strings or spaces in columns before performing calculations and analysis. I asked the AI to generate a function for handling missing prices, quantities, and dates sold, and then drop the rows with missing values. I also asked it to strip leading and trailing whitespace from product names and categories. To guide the AI, I used the prompts: “Strip leading/trailing whitespace from product names and categories because whitespace can cause issues with grouping and analysis” and “Handle missing prices, quantities, and dates_sold and drop rows with missing values because missing values are dangerous for analysis and should be removed.”

I renamed the column for stripping whitespace from product names and categories. I checked the column names and corrected the wrong column name 'product_name' to 'prodname'. For the handle missing values function, the AI did not realize that missing values are represented as empty strings and spaces. It used the dropna function when generating the code. I changed empty strings and spaces to NaN and then used dropna to clean the dataset.

I learned that even though AI can help generate code more efficiently, the correctness of the code is not guaranteed. When I used Copilot to strip the whitespaces from product names and categories, it did not check the column names and gave me the wrong column name 'product_name' instead of 'prodname'. Next time, I will give more specific prompts, such as providing the correct column name, and I will always check the AI-generated code. This experience taught me to carefully review the suggestions made by AI. Also, clear prompts are key to getting useful code from Copilot.
